Di mana dipasang? (rekomendasi penempatan)

account_circleChip header profil REKOMENDASI UTAMA

Chip "Premium · N hari" yang sudah ada di mockup profil → jadikan versi tier penuh ber-animasi. Profil adalah panggungnya: satu-satunya tempat animasi jalan terus, dilihat saat orang "berkunjung". Warna chip + ikon mengikuti tier (perunggu → holo).

badgeMikro statis di samping nama REKOMENDASI

Di kartu post timeline, balasan, dan header chat: ikon ✦ 15-16dp warna tier saja, TANPA animasi — timeline harus tetap tenang (perf + visual noise). Tier tetap terbaca dari warnanya; yang penasaran tinggal buka profil untuk lihat versi penuhnya.

touch_appTap badge → bottom sheet "Perjalanan Premium" REKOMENDASI

Momen "wah" sesungguhnya: tap chip/badge membuka sheet berisi badge besar ber-animasi penuh + progres ke tier berikutnya. Gamifikasi sekaligus jangkar retensi (tenure akumulatif = insentif untuk tidak berhenti langganan).

Compose: animasi offset Brush.linearGradient pada SpanStyle(brush = …).

storefrontPaywall & Settings OPSIONAL

Tampilkan ladder 5 tier di layar paywall/pengaturan Premium sebagai pitch retensi: "kumpulkan masa Premium-mu". Tier yang belum tercapai digambar redup (locked) — pola yang familiar dari battle-pass/Discord.

notificationsNotifikasi naik tier OPSIONAL

Saat tenure menyentuh ambang baru: notifikasi in-app "Badge kamu naik ke Emas ✦" + sheet perayaan sekali-tayang (confetti singkat). Tipe notifikasi baru — perlu masuk katalog NotificationType kalau diadopsi.

Catatan implementasi (Compose Multiplatform)

codeSemua efek bisa native Compose

  • Sweep/kilau: rememberInfiniteTransition + offset Brush.linearGradient yang digeser.
  • Cincin berputar: Brush.sweepGradient + graphicsLayer { rotationZ }.
  • Glow napas: animasi radius/alpha drawBehind (blur shadow) atau Modifier.shadow animasi.
  • Holo: animasi start/end offset gradien multi-warna.
  • Sparkle/bob: Canvas + transisi alpha/scale berjadwal. Tidak butuh Lottie; kalau mau lebih kaya, compottie tersedia untuk CMP.

speedDisiplin performa & aksesibilitas

  • Animasi hanya di profil + sheet; daftar (timeline/chat) selalu statis.
  • Hormati reduce-motion (Android ANIMATOR_DURATION_SCALE, iOS isReduceMotionEnabled) → fallback statis, seperti prefers-reduced-motion di halaman ini.
  • Pause animasi saat composable tidak terlihat (lifecycle-aware).
  • Satu sumber kebenaran tier: fun tenureTier(days: Long): TenureTier di modul shared.

databaseKebutuhan data (belum ada di backend)

  • Endpoint profil baru kirim isPremium boolean — perlu field tenure hari akumulatif.
  • Sumber paling natural: agregasi periode aktif dari subscription_events (tabel sudah ada di schema, status DESIGN untuk webhook RevenueCat).
  • Ambang tier: 30 / 90 / 180 / 365 hari — simpan sebagai konstanta shared, bukan magic number.
  • Tenure akumulatif ≠ streak: jeda langganan tidak menghanguskan hitungan (docs/01).
