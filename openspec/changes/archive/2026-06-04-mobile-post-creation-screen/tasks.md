Rethrow `CancellationException`.
- [x] 2.4 On the granted path: acquire `locationProvider.current()`, catching `LocationUnavailableException` → `LocationUnavailable` (no POST); otherwise POST and map `PostCreationApiResult` → `PostCreationOutcome` exhaustively (no wildcard): 201→`Success`; 400 keyed on `error.code` (`content_empty`/`content_too_long`/`location_out_of_bounds`/`content_moderated_profanity`), any other/absent 400 → `Error` + `diagnosticLog`; 5xx/IO → `NetworkError`; 401 delegated to the `Auth` plugin (not mapped here). The `diagnosticLog` sink's signature MUST be coordinate-free by construction (it receives only `status`/`errorCode`-style primitives — never `content` or the `LatLng`), so the no-coordinate-logging discipline is structural, not review-enforced.
