# NearYouID — Version Pinning Decisions Log

Single source of truth for the *why* behind each library version pin in `gradle/libs.versions.toml`.

## Pinning Policy

- All third-party library and plugin versions are declared in `gradle/libs.versions.toml`. Modules reference them via the typesafe `libs.*` accessor; raw `group:artifact:version` strings are forbidden (CI lint will enforce when added).
- Versions are **frozen** at Pre-Phase 1 baseline. Changes happen via deliberate bumps recorded in the table below — not via "latest stable" auto-resolution.
- Patch-level bumps (X.Y.**Z**) follow the auto-update flow (Dependabot/Renovate, separate change). Minor (X.**Y**) and major (**X**.Y) bumps require a row in the table justifying the change.

## Update Cadence

- **Patch**: monthly batch via Dependabot/Renovate PR (auto-merged after CI green).
- **Minor**: quarterly review; bump if a new minor unblocks a desired feature or fixes a CVE.
- **Major**: case-by-case; treated as a real change (proposal + design + tasks).
- **Security CVE**: immediate, out-of-band.

## 2026-06-10 Currency Batch (holistic audit)

One dated block instead of nine near-identical rows; full rationale + planned-upgrade list in [`docs/11-Engineering-Standards.md`](11-Engineering-Standards.md) § 1. All verified against ecosystem state 2026-06-10 via dated WebSearch (5 parallel research agents; sources: official release pages / Maven Central / vendor blogs).

- **Security (immediate):** `postgresql-jdbc` 42.7.7 → **42.7.11** (CVE-2026-42198, SCRAM PBKDF2 iteration DoS); `opentelemetry-instrumentation-bom` 2.25.0-alpha → **2.28.1-alpha** (2.26.1 fixed CVE-2026-33701) with `opentelemetry-bom` 1.51.0 → **1.62.0** — the version the instrumentation BOM *requests*, NOT the newest SDK (1.63.0): advancing the SDK ahead of its instrumentation pair broke at runtime (api 1.63 removed the internal `InstrumentationUtil` class that instrumentation 2.28.1 calls; caught by the test gate, NoClassDefFoundError on every instrumented route). Lockstep means "pair as co-released", not "both latest".
- **Direct bug in our stack:** `ktor` 3.4.1 → **3.5.0** — 3.4.3 fixed `HttpRequestLifecycle.cancelCallOnClose` × `CallLogging.callIdMdc` cascading request failures (both in our plugin set); 3.5.0 adds `requireQueryParameter`/`requireHeader` + suspending `authenticate()`.
- **Alignment:** `material3` (JetBrains) 1.10.0-alpha05 → **1.11.0-alpha07** (the CMP-1.11.x-aligned artifact; alpha line deliberate — stable 1.9.0 strips Expressive APIs).
- **Routine minors/patches:** `kotlin` 2.3.20 → **2.3.21**; kotlinx trio bumped together — `kotlinx-coroutines` 1.10.2 → **1.11.0**, `kotlinx-serialization` 1.9.0 → **1.11.0** (hides user input from JSON parse-exception messages — PII-safe logging win), `kotlinx-datetime` 0.7.1 → **0.8.0** (TimeZone serialization deprecated); `lettuce` 6.5.0 → **6.8.2** (last 6.x); `hikaricp` 6.3.2 → **6.3.3** (last 6.x).
- **Deliberately deferred** (each is a real migration, not a casual bump — triggers in docs/11 §1): Kotlin 2.4.0, AGP 8.13/9.x, kotest 6.x, Flyway 12.x, HikariCP 7.x, Lettuce 7.x, DataStore 1.2.1-KMP. Next review 2026-Q3.
